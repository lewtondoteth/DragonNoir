# Outlines

Chapter architecture, narrative beats, pacing references, and structural guides belong here.

Use this folder for:

- active chapter beat maps
- sequence architecture
- pacing and scene-function references
- structural guidance that governs prose without becoming prose itself

Do not use this folder for:

- canonical assembled chapter drafts
- experimental scene prose
- broad exploratory plot material that belongs in `../notes/`

When adding or changing a major outline, update the root README Chapter Status table if its status or use changes.
