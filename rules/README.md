# Writing Rules

Maintained practical writing rules for Dragon Noir belong here.

Use this folder for:

- approved narration rules
- reusable style and pacing guidance
- recurring anti-patterns discovered during drafting
- global or strongly reusable local patterns after validation

Do not use this folder for:

- one-off scene fixes
- unvalidated extraction summaries
- provisional plot scaffolds
- character, location, case, object, or organisation guidance that belongs in a profile

Candidate rules should pass through `../notes/rule_validation_workflow.md` before being added to maintained guidance, unless the author explicitly requests direct implementation and confirms the rule.
