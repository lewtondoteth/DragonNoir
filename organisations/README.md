# Organisations

Canonical organisation profiles and bounded organisation-guidance notes belong here.

Use this folder for:

- recurring groups, firms, factions, or institutions
- stable organisation behaviour and pressure logic
- what an organisation wants, hides, or makes possible in scenes
- how the organisation should be represented across future drafts

Do not use this folder for:

- throwaway invented names from exploratory drafting
- rejected draft variants
- vague worldbuilding that has not yet been validated

Exploratory organisation ideas should remain in `notes/` or issues until they are ready for profile treatment.
