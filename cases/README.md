# Cases

Canonical case profiles and bounded case-guidance notes belong here.

Use this folder for:

- active case profiles
- durable case summaries
- recurring case logic
- case-specific constraints that should remain accessible during drafting

Do not use this folder for:

- free exploratory scaffolds that have not been approved for profile treatment
- abandoned mystery variants
- raw transcript extraction output

Exploratory case shaping should stay in `notes/` until it is validated or logged for implementation.
