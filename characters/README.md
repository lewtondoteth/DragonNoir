# Character Profiles

Canonical character profiles and bounded character-guidance notes belong here.

Use this folder for:

- stable character facts
- recurring behaviour and voice guidance
- character-dynamic guidance that should survive across drafts
- bounded provisional character surfaces that support current case work

Do not use this folder for:

- raw exploratory character ideas
- unapproved names or relationships from drafting chats
- one-scene reactions that do not create durable guidance

Exploratory character material should be preserved through notes or issues first. Promote it into this folder only after validation or explicit implementation approval.
