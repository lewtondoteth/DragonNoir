# Objects

Canonical object profiles and bounded object-guidance notes belong here.

Use this folder for:

- recurring or important objects
- object identity and constraints
- what an object appears to be versus what remains hidden
- object-specific scene logic that should remain stable across drafts

Do not use this folder for:

- temporary one-scene props with no durable value
- raw exploratory wording
- unresolved object scaffolds that still belong in `notes/`

If an object is still provisional, preserve it through notes or issues first.
