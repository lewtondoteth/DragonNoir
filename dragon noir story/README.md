# Dragon Noir Story

This folder contains the standalone toy-noir Dragon book project.

## Authoritative Reference

- `story_bible/Toy_Noir_Dragon_Standalone_Story_Bible.md`

## Working Structure

- `chapters/` — chapter drafts or assembled chapter files
- `scenes/` — individual scene drafts, fragments, or scene-level experiments
- `notes/` — planning notes, continuity tracking, mystery structure, and revision notes
- `story_bible/` — authoritative noir project bible

## Use

Use this folder for the toy-noir detective continuity, chapter planning, scene drafting, and book-level structure.

Do not use the family story bible as guidance for this project unless explicitly asked.
