# AI Agent Instructions

## Repository Rule

This repository contains two separate Dragon projects:

- `dragon family story/`
- `dragon noir story/`

Treat them as separate canons, separate tones, and separate generation contexts unless the user explicitly asks to compare, adapt, or cross-reference them.

Do not import lore, tone, characters, settings, plot mechanics, themes, or continuity from one project into the other by assumption.

## Dragon Family Story

Use `dragon family story/Dragon_Stories_Story_Bible.md` as the authoritative reference for the family-story continuity.

This project is warm domestic fantasy with household scale, emotional safety, practical family logic, Dragon, Biffin, Addin, Bob, Mum, Dad, and the ordinary suburban Dublin house.

Keep work inside `dragon family story/` unless instructed otherwise.

Do not use the toy-noir bible to change family-story canon, tone, or behaviour unless explicitly asked.

## Dragon Noir Story

Use `dragon noir story/story_bible/Toy_Noir_Dragon_Standalone_Story_Bible.md` as the authoritative reference for the noir continuity.

This project is a standalone toy-noir book project. Keep chapters in `dragon noir story/chapters/`, scenes in `dragon noir story/scenes/`, and planning or continuity notes in `dragon noir story/notes/`.

Do not use the family story bible to change noir canon, tone, or plot unless explicitly asked.

## Cross-Project Work

Only compare or blend the projects when the user explicitly asks for cross-project analysis, adaptation, or contrast.

If a request says only "Dragon" and does not specify a project, infer from the files or folder named in the request. If the target remains unclear, ask which project to use before making canon-sensitive changes.

## Editing Discipline

Preserve each project's existing literary identity.

Prefer structural edits over creative invention when working on story bibles or planning documents.

Do not add new lore, relationships, motivations, or continuity unless the user specifically asks for that kind of creative development.
